# Government Agentic AI Recommendation System

## Project Overview
This project is an AI-powered government decision support system that helps senior authorities and committees recommend the most suitable officers for postings, transfers, and departmental leadership roles.

The system uses structured officer data from a CSV knowledge base and applies rule-based + AI-driven reasoning to generate transparent, explainable recommendations.

---

## Problem Statement
Government departments often face challenges in selecting the right officers due to:
- Lack of centralized officer performance data
- Complex hierarchy (BPS system)
- Manual and biased decision-making
- Limited visibility of expertise and experience

This system solves these issues using an Agentic AI approach.

---

## Solution
The system analyzes officer data and provides:
- Eligible officer filtering based on BPS rules
- Ranking based on performance, integrity, and experience
- Explainable AI recommendations
- Action simulation for postings/transfers
- Agent-based reasoning logs

---

## System Workflow (Agentic Architecture)

1. Request Understanding Agent  
2. Data Retrieval Agent (CSV dataset)  
3. Eligibility Filtering Agent (BPS rules)  
4. Ranking & Comparison Agent  
5. Decision Agent (Final recommendation)  
6. Simulation Agent (posting/transfer simulation)  
7. Logging Agent (agent traces)
